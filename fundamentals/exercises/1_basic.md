# Exercises: Values, Types, Functions, and if

Based on `fundamentals/lessons/1_basics.js`.

---

## Basic

1. Create a `const` called `city` with the value `"Berlin"`. Log it.
2. Create a `let` called `count` starting at `0`. Change it to `1`. Log it.
3. What type is `"42"`? What type is `42`? Check with `typeof`.
4. Create a boolean `isOnline` set to `true`. Log `typeof isOnline`.
5. Write a function `double` that takes one number and returns it times 2. Call it with `5`.

---

## Easy

6. Declare `let title;` without a value. Log `title` and `typeof title`.
7. Write `fullName(first, last)` that returns the two strings joined with a space. Call it with `"Ada"` and `"Lovelace"`.
8. Write an arrow function `isEven` that takes a number and returns `true` if it's even, otherwise `false`.
9. Store your age in `const age`. Write `canVote(age)` that returns `true` if age is 18 or more.
10. Write `trafficLight(color)` using `if` / `else if` / `else`: return `"go"` for `"green"`, `"wait"` for `"yellow"`, `"stop"` for `"red"`, and `"unknown"` for anything else.
